# Canada review record

13/13 jurisdictions. Three complete seed-42 contact sheets inspected at 560 × 352 per tile. All tiles, including the final Yukon row, reviewed each pass. Each directory retains its exact local source snapshot and JPEG sheet. Snapshots are documentary, not standalone modules (relative shared imports describe original layout).

Original decorative backgrounds only: no identity content, text, badges, seals, codes, or reproductions of official fine-line patterns. Follow-up research now documents directly inspected public specimens for all thirteen jurisdictions. Three use explicitly identified third-party reproductions (Newfoundland and Labrador, Nova Scotia, Nunavut); several samples are historic. Initial blocked-image gaps and successful retry provenance are recorded in sources.json. Historic specimens are not described as current. Geographic motifs are often original interpretation rather than objects observed on a licence.

## Provenance follow-up after pass 3

A bounded retry using a desktop User-Agent recovered official Alberta, New Brunswick and Yukon specimens. Public reproductions supplied Newfoundland and Labrador (Tests.ca), Nova Scotia (Global News, crediting the provincial government), and a historic Nunavut specimen (IDScan.net). All six were visually inspected. The Nunavut specimen has a 2007 issue field and must not be confused with the separately documented 2009 design. No art changes were required: landscape motifs remain original regional interpretations, not claims that those motifs occur on each licence. Passes 1–3 remain intact.
